# Triage labels

Use these canonical roles as local tracker `Status:` values.

| Role | Tracker value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

These are triage roles, not a replacement for completion notes or wayfinding's claimed/resolved states. Preserve completed tickets' implementation and verification records.
